# Documentación: RAG explicado desde cero

Guía en español para entender qué es RAG, cómo funciona y por qué conviene usarlo,
acompañada de una aplicación de ejemplo que puedes ejecutar y modificar.

| # | Capítulo | Para qué sirve |
| --- | --- | --- |
| 1 | [¿Qué es RAG?](01-que-es-rag.md) | La idea, el problema que resuelve y una analogía. |
| 2 | [Cómo funciona paso a paso](02-como-funciona.md) | Indexado y consulta: fragmentos, embeddings, búsqueda, prompt y generación. |
| 3 | [Beneficios y ventajas](03-beneficios-y-ventajas.md) | Los 8 beneficios, comparación con fine-tuning y contexto largo, casos de uso. |
| 4 | [Arquitectura del ejemplo](04-arquitectura-del-ejemplo.md) | Cómo está hecho este repositorio y cómo llevarlo a producción. |
| 5 | [Buenas prácticas y limitaciones](05-buenas-practicas-y-limitaciones.md) | Qué mejora la calidad, cómo evaluar y qué riesgos hay. |
| 6 | [Guía práctica: arma tu propio RAG](06-guia-practica.md) | Receta paso a paso para usar RAG con tus documentos y publicarlo. |
| 7 | [Sácale el jugo a RAG](07-sacarle-el-jugo.md) | Técnicas avanzadas por orden de impacto, diagnóstico de problemas y consejos para usuarios. |
| 8 | [Ejercicios](08-ejercicios.md) | Práctica guiada, de observar a construir. |
| 9 | [Glosario y recursos](09-glosario-y-recursos.md) | Términos clave y lecturas recomendadas. |

- **Voy a enseñar el tema:** todo en orden, con los ejercicios del capítulo 8 y la app abierta.
