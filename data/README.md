# Base de conocimiento de ejemplo

Estos documentos describen a **Bicicletas Aurora**, una empresa **ficticia**.
Se inventó a propósito: ningún modelo de lenguaje puede conocer estos datos
de antemano, así que cualquier respuesta correcta sobre ellos demuestra que la
información vino del paso de recuperación (la "R" de RAG) y no de la memoria
del modelo.

Puedes reemplazar estos archivos por tus propios `.md` o `.txt` y reiniciar el
servidor: se vuelven a indexar automáticamente al arrancar.
